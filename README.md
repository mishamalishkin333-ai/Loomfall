# Ткач Ярусов (Loomfall)

Атмосферная игра о Ткаче, который поднимается по ярусам подземного города и натягивает
нити, удерживающие чужую память. Unity 6 + URP, сборка в WebGL, публикация для VK и
Яндекс Игр.

Из семи ярусов осталось пять. Забвение стирает город сверху вниз, и каждый шаг Ткача
тратит память яруса: зажигать светильники и ткать нити можно только собранной памятью.

## Игра

| Что | Как устроено |
|---|---|
| Мир | пять ярусов; нижний двор 14×22 плитки, выше — четыре площадки на 4,4 / 8,8 / 13,2 / 17,6 м |
| Подъём | четыре наклонных въезда, каждый выводит на свой ярус |
| Осколки памяти | 8 в мире: их сбор — топливо для светильников и нитей |
| Светильники | 7 ламп, зажигаются за память, освещают ярусы |
| Нити | 3 нити у ткацкого узла; каждая требует собранного и зажжённого |
| Забвение | часы Забвения растут от трат Эха: Слово и Разрыв жгут память быстрее |
| Слово и Разрыв | магия Ткача: подсветка нитей и разлом камня ценой памяти яруса |
| Кодекс | 44 записи мира и 4 афоризма, открываются по ходу |
| Концовки | три: «Сброс», «Разрыв» и тайная «Третий узор» |
| Награда | вознаграждаемая реклама площадки даёт осколок памяти |

Тайная концовка не открывается «просто так»: узел отказывает, если собрано меньше
четырёх осколков, зажжено меньше двух светильников или Забвение перевалило за 0,4.
Это проверено живым прогоном: при пустом состоянии — отказ, при выполнении условий —
«Третий узор».

## Управление

На компьютере:

| Клавиша | Действие |
|---|---|
| W A S D | идти |
| Shift | бежать |
| Пробел | прыжок |
| E | натянуть нить (у узла) |
| Q | Слово |
| F | Разрыв |
| Tab | кодекс |
| R | реклама за награду |

На телефоне: палец в левой половине экрана ведёт Ткача (палец вверх — вперёд,
до края — бег), справа четыре кнопки: прыжок, нить, Слово, Разрыв. Кнопки появляются
только на устройствах с сенсорным экраном.

## Качество картинки

- URP с постобработкой: ACES-тонмаппинг, свечение, грейд, виньетка, зерно.
- Свет: холодный луч сверху, тёплая подсветка ярусов, экспоненциальный туман глубины.
- Профиль качества выбирается по устройству: на телефоне сглаживание выключено, карта
  теней 1024 и один каскад; на компьютере — MSAA 2×, 2048 и четыре каскада.
- Анимации: покой, бег, прыжок; контроллер состояний с параметрами `speed` и `jump`.
- Звук: сгенерированный гул глубины, 22050 Гц, моно, 6 секунд, без стыка на петле.

## Площадки

Игра работает и как обычный сайт, и внутри VK и Яндекс Игр. Мост к площадкам —
`Assets/Plugins/WebGL/LoomfallBridge.jslib`, вызовы из C# — `PlatformBridge.cs`.

| Площадка | Что подключено |
|---|---|
| VK | `VKWebAppInit`, `VKWebAppStorageGet` / `VKWebAppStorageSet`, `VKWebAppShowNativeAds` |
| Яндекс Игры | `YaGames.init()`, `LoadingAPI.ready()`, `getPlayer().getData/setData`, `showRewardedVideo` |

Без площадки игра тоже запускается: сохранения уходят в память браузера, реклама
пропускается, исключений не возникает.

## Сборка проекта

```
Unity.exe -batchmode -nographics -quit -projectPath . -executeMethod Loomfall.EditorTools.LoomfallCore.SetupAndBuild -logFile build.log
```

Готовый архив появляется в `C:/Unity/build/webgl`: `index.html` в корне, данные, WASM и
загрузчик — в подкаталоге `Build/`. Архив: **12,28 МБ, 18 файлов** при лимите площадок
100 МБ.

## Проверки

Игра проверена не «на глаз», а замерами — подробности в [VERIFY.md](VERIFY.md).

| Что | Результат |

| Скорость ходьбы / бега | 3,01 из 3,20 м/с и 6,32 из 6,40 м/с |
| Бег через сенсорный ввод | 6,32 из 6,40 м/с — путь с телефона работает |
| Живой прогон | 600 кадров, 0 исключений, подъём на все пять ярусов |
| Мост к площадкам | 15 из 15 проверок на подставных SDK |
| Управление и профиль качества | 16 из 16 проверок |
| Интеграция площадок в сборке | вызовы в движке и импорты `Loomfall*` в wasm — на месте |
