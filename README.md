# Ткач Ярусов (Loomfall)

Атмосферная игра о Ткаче, который натягивает нити между ярусами подземного города.
Unity 6 + URP, сборка в WebGL, публикация для Яндекс Игр и VK.

## Что уже в игре

- Нижний двор первого яруса, собранный из 40 модулей подземного кита: плитка пола,
  три яруса кладки, углы, лестница, ворота.
- Ткач — модель с ригом и анимациями покоя, бега и прыжка; контроллер состояний
  с параметрами `speed` и `jump`.
- Управление от третьего лица: WASD, бег на Shift, прыжок на пробел.
- Ткацкий узел во дворе с подсказкой взаимодействия.
- Экранный слой: задача яруса, подсказки управления, зов у узла.
- Свет: холодный луч сверху, тёплая подсветка, туман глубины, тонкая настройка
  по замерам кадра.
- Постобработка URP: тонмаппинг, свечение, грейд, виньетка, зерно.

## Управление

| Клавиша | Действие |
|---|---|
| W A S D | идти |
| Shift | бежать |
| Пробел | прыжок |
| E | натянуть нить (у ткацкого узла) |

## Сборка проекта

```
Unity.exe -batchmode -nographics -quit -projectPath . \
  -executeMethod Loomfall.EditorTools.LoomfallCore.SetupAndBuild -logFile build.log
```

Готовый архив появляется в `C:/Unity/build/webgl`: `index.html` в корне,
данные, WASM и загрузчик — всё в подкаталоге `Build/`.

## Сцены

| Сцена | Что это |
|---|---|
