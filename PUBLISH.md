# Публикация «Ткача Ярусов»

Репозиторий уже создан локально и закоммичен. Игра лежит в `docs/` — этот каталог
GitHub Pages отдаёт как статический сайт.

## Шаг 1. Репозиторий на GitHub

Вариант А (я делаю сам, нужен ваш вход):

```
winget install --id GitHub.cli
gh auth login          # вход через браузер, токен мне присылать не нужно
powershell -NoProfile -ExecutionPolicy Bypass -File publish.ps1 -DryRun
```

`-DryRun` ничего не публикует, а показывает состояние: ветку, число коммитов, размер
архива и готовые ссылки. Флаг `-NoProfile` нужен, потому что чужой профиль PowerShell
может печатать свои ошибки и возвращать ненулевой код — это выглядит как сбой скрипта,
хотя он отработал.

Если `gh` ставить не хочется, скрипт печатает ручной путь: создать пустой репозиторий
на сайте, добавить `origin`, запушить `main` и включить Pages из папки `/docs`.

После этого я создаю репозиторий и включаю Pages одной командой.

Вариант Б (вы делаете сами):

```
cd C:\Unity\Loomfall
git remote add origin https://github.com/ВАШ_НИК/loomfall.git
git push -u origin main
```

## Шаг 2. Включить GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: **main**, папка **/docs** → Save.

Через 1–2 минуты сайт будет доступен по адресу:

```
https://ВАШ_НИК.github.io/loomfall/
```

Политика конфиденциальности (обязательна для VK):

```
https://ВАШ_НИК.github.io/loomfall/privacy.html
```

## Шаг 3. Карточка приложения в VK

| Поле VK | Что вписать |
|---|---|
| Название | Ткач Ярусов (Loomfall) |
| Адрес приложения | `https://ВАШ_НИК.github.io/loomfall/` |
| Адрес политики конфиденциальности | `https://ВАШ_НИК.github.io/loomfall/privacy.html` |
| Платформа | HTML5 (Web) |
| Категория | Игры → Приключения |
| Возраст | 12+ (атмосферная тема, без жестокости) |
| Оплата | Пока отключена; при включении — только `VKWebAppShowOrderBox` |
| Реклама | `VKWebAppShowNativeAds` (межстраничная и вознаграждаемая) |
| Сохранения | `VKWebAppStorageSet` / `VKWebAppStorageGet` |

Требования, которые сборка уже выполняет: `index.html` в корне архива, размер
12,28 МБ при лимите 100 МБ (18 файлов), все файлы отдаются по HTTPS без особых
заголовков, игра работает в iframe, управление — клавиатура на компьютере и палец
на телефоне, профиль качества выбирается по устройству.

## Обновление игры после правок

```
cd C:\Unity\Loomfall
robocopy C:\Unity\build\webgl docs /MIR
git add -A
git commit -m "Обновление сборки"
git push
```

`/MIR` полностью синхронизирует `docs/` с новым архивом — старые файлы
сборки не останутся в репозитории.
